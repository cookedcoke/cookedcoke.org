# Photos

## `team.jpg` — the crew photo on the home page

Drop a photo of the team here as `team.jpg` and it appears in the hero
automatically. Until the file exists, that slot shows a brand-red panel with the
mark, so the page never looks unfinished.

- Landscape, 4:3 works best (it is cropped to fill a 4:3 frame), at least 1600×1200.
- JPEG, under ~400 KB. Export at quality 75–80.
- Shoot it on Level 7 if you can — the place is part of the story.

**Before you add it:** most of the team are school students, so check the
school's media consent rules first. If faces are a problem, a shot from behind
the counter, hands only, or back-of-heads gives most of the same effect.
